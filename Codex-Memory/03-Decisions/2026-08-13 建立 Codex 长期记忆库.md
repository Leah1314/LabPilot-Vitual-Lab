# 建立 Codex 长期记忆库

## 决策

使用本地 Obsidian Vault 作为 Codex 跨项目长期记忆的规范存储，并在每天 22:00 整理当天沟通。

## 目的

- 沉淀长期决策、行为偏好、项目状态和可复用细节。
- 通过短小 Context Pack + 按需深读，减少冗余读取。

## 约束

- 不收集秘密或高敏感数据。
- 自动化仅总结其实际可访问的沟通；不能假设覆盖所有平台或不可见任务。
- 跨项目使用时，各项目仍需显式指向本 Vault 的 `Context Pack`。
