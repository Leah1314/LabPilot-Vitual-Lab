# Codex 记忆读写协议

## 每个任务开始

1. 读取 [[00-System/Context Pack]]。
2. 只沿与当前任务有关的链接深读。
3. 若记忆与用户当前指令冲突，以当前指令为准并记录变化。

## 每个任务结束

仅在出现以下内容时建议写入：新决策、稳定偏好、项目状态变化、可复用教训。不要写入普通执行日志或可从 Git 重建的细节。

## 每晚整理

1. 汇总当天可访问的 Codex 沟通，写入 `02-Daily/YYYY-MM-DD.md`。
2. 去重并抽取记忆候选；不确定项写入 `01-Inbox`。
3. 更新相关项目、决策、偏好和 Playbook。
4. 仅把高置信、仍有效、跨任务复用的信息放入 Context Pack。
5. 更新 [[00-System/Automation State]]，记录来源时间窗。
