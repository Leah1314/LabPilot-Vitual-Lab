# Memory Policy

## 可写入

- 已明确表达且未来会复用的偏好
- 有理由、替代方案和结果的重要决策
- 项目目标、约束、状态、关键路径和复盘
- 重复出现两次以上的有效工作方式

## 只进 Inbox，等待确认

- 从单次行为推断出的习惯
- 对动机、性格、关系或价值观的推测
- 可能已经过时或缺少来源的信息

## 禁止写入

- 密码、密钥、Token、恢复码
- 身份证件、银行卡和精确财务账户信息
- 无必要的医疗、法律或第三方隐私信息
- 大段逐字聊天、可从源码或原始文档轻易重建的内容

## 生命周期

1. Capture：写入每日记录或 Inbox。
2. Distill：提炼为事实、决策、偏好、项目状态或 Playbook。
3. Verify：附日期、来源、置信度；低置信内容不进入 Context Pack。
4. Promote：重复出现或用户明确确认后，提升为长期记忆。
5. Supersede：新结论链接旧结论；旧条目标记 `superseded`。
6. Archive：完成项目和失效内容移至 Archive，但保留可追溯性。
