# Codex Memory

这是一个本地 Obsidian Vault，也是 Codex 的长期记忆库。

## 使用方式

1. 在 Obsidian 中选择“打开本地仓库”，指向本目录。
2. 新任务开始时，让 Codex 先读 `00-System/Context Pack.md`。
3. 需要历史依据时，再按其中的链接读取具体决策、项目或偏好文件。
4. 当你说“记住这件事”时，先写入当日日志；确认稳定后再提升到长期记忆。

## 原则

- 只保存未来可能复用的信息，不保存完整聊天转录。
- 每条长期记忆包含来源、日期、置信度和复核日期。
- 新信息不直接抹掉旧信息；先标为已替代，并链接到新结论。
- 不保存密码、API Token、身份证件、银行卡、医疗隐私或第三方敏感信息。
- 对“习惯”和“偏好”使用可修订措辞，不把阶段性行为永久人格化。

## 目录

- `00-System`：入口、规则与自动整理状态
- `01-Inbox`：尚未确认或归类的记忆候选
- `02-Daily`：每日沟通摘要
- `03-Decisions`：重要决策及理由
- `04-Preferences`：稳定的工作与沟通偏好
- `05-Projects`：项目索引、状态和经验
- `06-Playbooks`：可复用流程
- `07-People`：仅保存工作所需、非敏感的关系上下文
- `08-Archive`：已完成或被替代内容
- `Templates`：Obsidian 模板
